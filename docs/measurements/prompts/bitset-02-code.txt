The following Python function is supposed to return the median of a list of numbers, but it gives wrong answers for some inputs and crashes for others.

def median(values):
    values.sort()
    n = len(values)
    mid = n / 2
    if n % 2 == 0:
        return values[mid] + values[mid + 1] / 2
    else:
        return values[mid]

print(median([3, 1, 2]))
print(median([4, 1, 3, 2]))
print(median([]))

Explain every bug in this function, one by one, and say which of the three calls above triggers each of them. Then write a corrected version that does not modify the caller's list, raises a ValueError with a clear message for an empty list, works for both integers and floats, and includes a short docstring. Finally, list three test cases you would add to make sure the bugs cannot come back, with the expected result of each.
